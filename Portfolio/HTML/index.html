HR HC DASHBOARD ANALYSIS

The HR Headcount Analysis Dashboard provides a clear overview of employee data and workforce trends using interactive visualizations. The dashboard analyzes key metrics such as total headcount, employee distribution by department, job role, gender, age group, and employment status. It helps identify workforce patterns, monitor employee growth, and compare departmental headcount efficiently. Built using **Excel, Power Query, and Power BI**, the dashboard transforms raw HR data into meaningful insights that support better workforce planning and data-driven decision-making.

CHILD WELFARE AND ORPHANAGE MANAGEMENT PLATFORM

The Child Welfare and Orphanage Management Platform designed to simplify and improve the management of orphanage activities and child welfare services. The platform manages child profiles, orphanage registration, staff and volunteer details, donations, resources, and welfare records through a centralized system. It also provides dashboards and reports to help administrators monitor activities and make informed decisions. Developed using **React.js, Node.js, MySQL, and online APIs**, the platform aims to improve data management, reduce manual work, and support efficient and compassionate child care.

LIBRARAY MANAGEMENT SYSTEM

The Library Management System is a database-driven application designed to efficiently manage library operations and records. The system handles information related to books, members, employees, book issuing and returns, branches, and fines. It uses SQL queries, joins, grouping, procedures, and database operations to organize and analyze library data effectively. Developed using **PostgreSQL and pgAdmin**, the project helps reduce manual record management, improve data accuracy, and streamline daily library activities.
